Module 01 · Continuous model

Normal Distribution

Manufacturing Quality Control — use measurements to estimate the proportion of shafts that meet the required diameter specifications.

Industry problem

A factory manufactures shafts with a target diameter of 10 mm. Small manufacturing variations cause the measured diameters to vary around a mean. Assume the diameter follows a normal distribution. The acceptable diameter is between 9.90 mm and 10.10 mm.

The default example uses μ = 10 mm and σ = 0.05 mm. Change the values to explore different production conditions.

Input parameters

Mathematical model

X ~ N(μ, σ²)
f(x) = [1 / (σ√(2π))] exp(−(x−μ)² / (2σ²))
P(a ≤ X ≤ b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)

Φ(z) is the cumulative distribution function (CDF) of the standard normal distribution.

Module 02 · Continuous model

Exponential Distribution

Cloud Request Inter-arrival Time — model the waiting time between consecutive incoming requests.

Industry problem

A cloud service receives requests at an illustrative average rate of 12 requests per minute. Assuming requests follow a constant-rate Poisson arrival process, the time between consecutive requests can be modelled using an exponential distribution.

Important: Inter-arrival time is the time between request arrivals. It is not the same as server response time or request-processing time.

Input parameters

Mathematical model

T ~ Exponential(λ)
f(t) = λe^(−λt), t ≥ 0
P(T ≤ t) = 1 − e^(−λt)
P(T > t) = e^(−λt)
P(T > t₂ | T > t₁) = e^(−λ(t₂−t₁))

The λ used in these formulas must use the same time unit as t. This application converts requests/minute into requests/second before calculating.

Module 03 · Sampling distribution

Central Limit Theorem

Warehouse Processing Time — understand why averages from repeated samples tend to form an approximately normal distribution.

Industry problem

A warehouse operations team studies the time required to process orders. Individual order-processing times may have a distribution that is not normal. The team repeatedly selects random samples of orders and calculates the average processing time for each sample.

Learning inputs

The population mean, population standard deviation, and sample size are the key quantities used when studying the sampling distribution of the sample mean.

Input controls and numerical example

This module's calculation and visualization are reserved for the next implementation prompt, because no numerical warehouse example or specific CLT calculations were supplied.

Mathematical idea

E[X̄] = μ
SD(X̄) = σ / √n
X̄ ≈ N(μ, σ²/n) for sufficiently large n

The approximation becomes useful under the Central Limit Theorem when observations are independent and identically distributed with a finite mean and variance. The required sample size depends on the population distribution.

What students will explore

  • How sample size affects the standard error.
  • Why sample averages become more concentrated around the population mean as n increases.
  • How the sampling distribution can be approximately normal even when individual processing times are not normally distributed.
